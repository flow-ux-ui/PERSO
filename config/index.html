In-game overlay ▸
Ctrl+Shift+O toggles the overlay between click-through (lets clicks pass through to the game) and interactive (drag/resize it). Ctrl+Shift+H shows/hides it entirely. The overlay only shows the fight currently being viewed here (Prev/Next fight still works).
Parsing rules ▸
Marks who is acting. Every damage/heal line that follows is credited to this caster, until the next match. Needs a caster group.
Matches e.g. Ayendas: +1 810 PV (Feu) (heal) or Nox: -72 082 PV (Air) (damage). Needs target, sign, amount groups. Space thousand-separators are handled automatically.
Each match starts a new turn. Add a (?<num>\d+) group instead if your log states explicit turn numbers.
Channel filter (optional) ▸
Lines that don't contain this exact text are ignored for damage/turn parsing — filters out chat (Commerce, Guilde, Communauté…), engine/Lua noise, etc. Start/stop keywords below are still recognized on every line regardless of channel, since players usually type those in chat, not in the combat channel. Leave empty to parse every line like before.
Combat window (optional) ▸
Matches any line ending in : keyword, e.g. typing start catches Ash: start. Everything before this line is ignored. Leave empty to parse from the first line.
Same idea, e.g. Ash: stop. Everything after is ignored, until the next start keyword (if any) turns it back on. Leave empty to parse until the end.
Combat boundary (optional) ▸
Matches any line containing this text exactly as written (not a Name: keyword line — this one has no caster). Every occurrence splits the log into a separate fight, each with its own roster/meter/charts, browsable with the Prev/Next fight buttons above the results. If no Start keyword above is set, Watch File (Live) and Reset Tracking also jump straight to the last occurrence instead of replaying every past fight. Leave empty to disable (treats the whole log as one fight).
Ownership rules (optional) ▸
One rule per line: spell(s) -> tags: name(s) / summons: name(s). Comma-separated lists, everything case-insensitive, tags: and summons: both optional (need at least one).

Whoever casts one of the spell(s) on the left becomes that rule's current "owner". From then on: any HP-change line tagged with one of the tags (the text in parentheses, e.g. Ash: -500 PV (Intoxiqué)) is credited to the owner instead of whoever's turn it is — this covers delayed DOT ticks. Any damage dealt by one of the summons acting on its own turn (its own "lance le sort" line) is also credited to the owner instead of the summon itself — this covers invocations that play independently.

Add more lines for more owner spells. Leave the whole box empty to disable this feature entirely.
Hide character(s) (optional) ▸
Type a name and press Enter (or comma) to hide them, or click the × next to a name in the roster or breakdown table. Damage credited to hidden casters disappears from the meter, chart, table and roster — damage they receive from someone else is unaffected. Click the × on a chip below to bring someone back.

Deduplication (optional) ▸
The game sometimes logs the exact same event twice a few ms apart — that's a true duplicate. But identical text can also be two genuinely separate hits (e.g. a counter-attack that always deals the same fixed damage) seconds apart — those should both count. Only pairs within this window are treated as duplicates. Ignored if the line has no parseable timestamp (falls back to plain text match).
